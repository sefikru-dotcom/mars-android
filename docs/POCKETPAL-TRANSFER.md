# Перенос механик PocketPal в локальный чат Марса

Источник: /root/workspace/pocketpal-research/pocketpal-ai (f8f37d9, 1.22.0). Наш код: рабочая копия mars-android на ноутбуке (локальный контур целиком untracked).

Область: только локальный чат с прямыми провайдерами. Серверный чат второстепенен.

## Факты текущего состояния

- Параметры живут на ПРОФИЛЬ провайдера (`LocalProviderProfile`), а не на модель: смена модели тащит temperature/maxTokens дальше (`LocalModelPick.apply`).
- `buildRequestBody` отправляет только `temperature`, `max_tokens`, `reasoning_effort`; остального сэмпсинга нет.
- Каталог уже читает `context_window`, `max_output_tokens`, `reasoning_controls` — основа для пер-модельных дефолтов есть.
- `usage` парсится, пилюля контекста и лист действий (копировать/выбрать/озвучить/файл) есть.
- Barge-in настоящий: `BargeInGate` + `AudioCapturePolicy` (`VOICE_COMMUNICATION` с AEC/NS, откат на `MIC`).

## Ключевая поправка

У PocketPal **нет** пер-модельных дефолтов: каскад идёт `system → global → pal → session`, а `Model.completionSettings` не читается. Пер-модельные дефолты — наша новая фича. Копируем не хранение, а три механики: таблицу параметров, правило «дефолт не отправляется», явный источник настроек.

## Фильтр под личное приложение (что выкинуто из заимствований)

- Каскад из четырёх уровней и «применить к пресету» → хватит двух: дефолт модели и переопределение сессии.
- Подписи-абзацы под каждым полем → короткие границы прямо в поле.
- Число «провайдер сам, 0.95» → только «провайдер сам»: облачные API значение не сообщают, `/props` есть лишь у llama-server.
- Три состояния пустого экрана и приветствие-бабл → у нас один экран с сессиями, состояния уже есть; приветствие не приоритет.
- Автодетект типа сервера дебаунсом → достаточно имеющейся кнопки «Проверить», а тип API важнее дать выбрать вручную: от него зависит маппинг полей.
- Человекочитаемые тексты ошибок → для себя достаточно кода и границ.

Оставлено твёрдо: то, что влияет каждый день и дешево — смена модели не переносит параметры, полный набор сэмпсинга, «дефолт не шлём», двухфазный стоп, ретрай обрыва, метрики, гистерезис, черновики, coalesce, undo-ввод, «повторить другой моделью».

## Волна 1 — параметры

1. `SamplerParams.kt`: ключ, wire-имя, min/max/step/default, флаг «слать всегда».
   Референс: `src/utils/modelSettings.ts:27-133`, `src/utils/samplerParams.ts:9-74`.
   Набор: temperature, top_p, top_k, min_p, typical_p, penalty_repeat/freq/present/last_n, mirostat(+tau/eta), seed, stop, max_tokens, reasoning_effort.
2. `ProviderApiType` (openai / llama-server / ollama) с маппингом имён и набором допустимых полей — чтобы top_k не уходил туда, где его нет. Референс: `src/api/servers/index.ts:41-90`.
3. `ModelDefaultsStore`: дефолты на `baseUrl+modelId` из каталога + ручные оверрайды; сброс при удалении профиля.
4. `LocalTurnSettings` на сессию со снапшотом и `settingsSource`. Смена модели берёт дефолт новой модели либо «провайдер сам».
5. Шторка «Параметры хода»: поля с шагом, быстрые пресеты (точный / баланс / креатив / сырой), «провайдер сам» с тапом, сброс к модели. Валидация по таблице.
6. `buildRequestBody` читает `LocalTurnSettings`; профиль хранит только адрес, ключ, тип API, заголовки, имя, модель.

Приёмка: смена модели меняет эффективные параметры; дефолтное поле отсутствует в теле; температура живёт только у своей модели.

Ломаются: `LocalModelSwitchTest`, `LocalModelPickerPolicyTest`, тесты настроек.

## Волна 2 — лента и действия

1. Двухфазный стоп: abort сигнала, затем гашение записи UI; частичный ответ сохраняется с `interrupted`, пустой удаляется. Референс: `useChatSession.ts:918-1141`.
2. Ретрай на обрыв SSE (у них нет): backoff, повтор только если токенов не было; классификация ошибок в тип.
3. Undo-ввод: ошибка до первого токена → вернуть текст и вложения в композер.
4. Футер: `ttft`, `tok/s`, статус обрыва; «нет поля — нет строки». Референс: `AssistantTurnFooter.tsx:57-113`.
5. Гистерезис скролла 24/40, кнопка «вниз» только при скрытом контенте. Референс: `ChatView.tsx:495-544`.
6. Coalesce-слот стрима ~30 мс, запись на диск на финализации.
7. Черновик на сессию с возвратом.
8. «Повторить другой моделью» в листе действий. Референс: `useMessageActions.ts:108-121`.

## Волна 3 — голос

1. Речь по первому клаузу, батчи ~300 символов, фаза «говорит» по первому реальному аудиочанку, стоп прошлого стрима строго до старта нового. Референс: `streamingHandle.ts:14-110`, `TTSStore.ts:728-806`.
2. Watchdog микрофона 3 с с одним рестартом, settle 150 мс, явная обработка аудио-прерываний.
3. Пять фаз, писать фазу только из контроллера; «Hmm, let me think» вместо тишины на reasoning.

## Наши расширения сверх PocketPal

- **Режимы (роль + промпт + параметры + модель)** — их персоны без маркетплейса: код, авто/VAG, офис, «сырой». Сессия наследует режим, правится на месте.
- **Варианты ответа**: несколько ассистентских строк на один ход с переключением — вместо их деструктива.
- **Продолжение генерации** и перегенерация только последнего шага.
- **Удаление одного сообщения** без сноса хвоста.
- **Снимок параметров в сессии** → «перезапустить с теми же».
- **Стоимость хода** по прайсу провайдера в футере (есть скилл цен).
- **Сравнение двух моделей на одном промпте** (side-by-side): у них только локальный бенч tok/s.
- **Экспорт сессии целиком** в md — «сохранить как файл» уже есть, добавить весь диалог.
- **Ничего не фильтровать**: reasoning не схлопывать по умолчанию, не резать длину, лимит HTML-превью не 5, а по памяти.

## Не брать

- Half-duplex: у нас barge-in и AEC, микрофон не закрываем.
- Перегенерация удалением хвоста.
- Персоны с маркетплейсом и PalsHub.
- `DynamicParameters` (их слой персон на react-hook-form).
- Всё локальное: тиры, GGUF, кванты, `n_ctx/n_threads/gpu_layers`, RAM-бюджеты, докачка, BOS/EOS, шаблоны чата.
- `marked` + `render-html`.

## Риски

- Без каталога дефолт неизвестен: честное состояние — «провайдер сам», а не выдумка по имени модели.
- Без `settingsSource` параметры «мигают» при возврате в сессию — источник обязателен.
- Шторку не открывать во время стрима: правка не должна влиять на текущий ход.
- `stream_options.include_usage` — всегда, на нём пилюля и футер.
- Пресеты не должны перебивать «провайдер сам» молча: выбор пресета — явное действие.

## Приёмка

Живой прогон на POCO F5 с реальным провайдером: смена модели меняет дефолты; дефолтные поля не уходят в лог тела; сброс возвращает «провайдер сам»; обрыв на первом токене возвращает ввод; футер показывает ttft и статус; лента не дёргается при чтении выше.
