## Что сделано (волна 1)

### core-network
- `SamplerParams.kt` — таблица параметров: wire-имя, min/max/step, дефолт приложения,
  признак «отправляем всегда». Значение хранится с типом (int против double): часть
  посредников отвергает `max_tokens: 200000.0`.
- `LocalTurnSettings.kt` — параметры одного хода, явными полями (не мапой): типы ловят
  ошибки на компиляции. `null` = «провайдер сам». Есть `defaultsFor`, `merge`, `toJson`,
  `fromJson`, `SettingsSource { DEFAULT, MODEL, SESSION }`.
- `LocalChatClient` — перегрузка `stream(..., settings: LocalTurnSettings? = null)` с
  реализацией по умолчанию: транспорт, который про настройки не знает, работает как раньше.
  Сделано перегрузкой, а не пятым параметром, потому что Kotlin требует от реализаций
  повторять сигнатуру целиком — пятый параметр сломал бы `UnavailableClient` и три фейка.
- Правило провода: `temperature`/`top_p` уходят всегда (наш дефолт может отличаться от
  дефолта посредника), `max_tokens` — если задан, остальное — только если человек трогал.
- Сквозной тест `LocalTurnSettingsBodyTest` на MockWebServer проверяет именно ТЕЛО запроса:
  `settings == null` даёт прежнее тело, заданные значения уходят под wire-именами,
  не заданные — не уходят вовсе.

### app-mobile
- `LocalTurnSettingsPolicy.kt` + `LocalTurnSettingsSheet.kt` — шторка «Параметры хода»:
  чип в шапке (со звёздочкой при изменённых значениях), ползунки с границами из таблицы,
  «провайдер сам» как явное состояние, стоп-последовательности чипами, сброс к дефолтам
  модели. Логика отделена от Views — 17 тестов без эмулятора.
- `LocalChatPresenter` — снимок параметров в мете сессии, `setTurnSettings`,
  `restoreTurnSettings`, `turnSettingsCustom`.
- Лента: двухфазный стоп (сначала гейт дельт, потом отмена и финализация в `finally`),
  возврат ввода при сбое до первого токена, «повторить другой моделью», гистерезис
  автоскролла 40/24dp, футер с расходом, `interrupted` и `ttft`.
- Голос: `SpeechChunker` (первый клауз, дальше пачки ~300 символов по границе слова),
  `MicCaptureWatchdog` (3 с без чанка → один перезапуск → сдача с сообщением),
  `onAnswerStarted`/`onAnswerDelta`/`onAnswerEnded`/`onReasoningStarted` в контроллере и
  кнопке, потоковая озвучка на экране (счётчик `voiceSpokenChars` не даёт повторять).

### Экран
`LocalChatActivity` получил: `onUndoInput` (возврат текста и вложений в поле),
`state.stopping` (кнопка гаснет), потоковую озвучку по дельтам, список моделей и
`onRetryWith` для повтора другой моделью.

## Что осталось честно не сделанным

1. **`tok/s` не выводится.** Провайдер отдаёт `usage` одним кадром в конце, без отметок
   времени — считать значило бы выдумывать. `ttft` измеряется честно (от старта хода до
   первого символа).
2. **`truncated` (упор в лимит токенов).** Поле готово, но транспорт ядра не пробрасывает
   `finish_reason`. Нужна правка `LocalChatEvent`/парсера SSE, потом выставить флаг.
3. **Метрики не сохраняются в историю:** `LocalMessage` в core-network не несёт
   `usage`/`interrupted`, поэтому после перезапуска футера нет.
4. **Фаза «говорит» включается по принятому синтезу, а не по первому аудиочанку:**
   события реального старта в `SpeechEngine` нет (`UtteranceProgressListener.onStart`
   объявлен пустым). Ограничение записано в KDoc `LocalVoiceTts`.

## Грабли сборки на сервере (для следующего раза)

- `gradlew` в снимке ноутбука с CRLF — падает с `bad interpreter`. Лечится `sed -i 's/\r$//'`.
- `local.properties` ноутбука смотрит на `C:/android-sdk` — на сервере нужен
  `sdk.dir=/root/android-sdk`.
- `app-mobile` требует `app-mobile/google-services.json` — брать из `/tmp/lap`
  (распакованный бандл ноутбука), а не FCM-ключ из `/root/.secrets`.
- Gradle-демон иногда зависает на `testDebugUnitTest` с фильтром `--tests` — помогает
  `pkill -f "GradleDaemon 8.2"` и повторный прогон.
- Сборки только по одной (flock + systemd-лимиты памяти): пять параллельных Gradle
  раньше роняли сервер.
- `LocalSessionStoreTest.pruneDeletesOldestBeyondLimit` был плавающим: `save` ставит
  текущее время, три сохранения подряд получали одну миллисекунду. Теперь `now` передаётся
  явно.
